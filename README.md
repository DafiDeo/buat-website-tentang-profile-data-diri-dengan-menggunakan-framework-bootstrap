## 📖 Tentang Project

Project ini merupakan latihan membuat **website profile data diri** menggunakan **HTML, CSS, dan framework Bootstrap**.

Tujuan dari project ini adalah mempelajari bagaimana membuat halaman web yang memiliki tampilan lebih terstruktur, responsif, dan menarik dengan memanfaatkan komponen yang tersedia pada Bootstrap.

---

Website dapat dijalankan melalui **GitHub Pages**:

👉 [Buka Demo Website](https://dafideo.github.io/buat-website-tentang-profile-data-diri-dengan-menggunakan-framework-bootstrap/Profile_Data_Diri.html)

## 🛠️ Pemograman yang Digunakan

| Pemograman | Kegunaan |
|---|---|
| 🟧 HTML5 | Membuat struktur halaman |
| 🎨 CSS3 | Mengatur dan menyesuaikan tampilan |
| 🟪 Bootstrap 5.3.8 | Membantu membuat layout dan komponen |
| ⭐ Bootstrap Icons | Menambahkan ikon pada website |
